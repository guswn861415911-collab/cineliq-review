제1조 목적 및 적용 범위

CINELIQ는 AI 이미지·영상 제작에 쓰이는 카메라 기법을 탐색하고 학습하는 서비스입니다. 이 방침은 웹사이트 방문, 회원가입·로그인, 계정 관리 및 즐겨찾기 이용 과정에 적용됩니다. 기법 검색과 열람, 프롬프트 복사는 비회원도 이용할 수 있습니다.

제2조 처리하는 개인정보

이메일 가입·로그인. 입력한 이메일 주소와 비밀번호를 Supabase Auth에 전송해 인증합니다. CINELIQ 웹사이트는 비밀번호를 별도로 저장하지 않습니다. 비밀번호 재설정을 요청하면 입력한 이메일 주소를 Auth에 전송합니다.

Google 로그인. Google 계정 식별자, 이메일 주소와 이메일 확인 여부를 인증에 사용합니다. Google이 제공하는 경우 표시 이름과 프로필 사진 URL이 Supabase Auth의 계정 메타데이터에 포함될 수 있습니다. 처리 경로는 제4조에서 설명합니다.

카카오 로그인. 카카오 계정 식별자를 로그인에 사용합니다. 이용자가 동의하고 카카오가 제공하는 경우 이메일 주소, 닉네임과 프로필 사진 URL이 Supabase Auth의 계정 정보 또는 인증 메타데이터에 포함될 수 있습니다. 이메일 주소를 제공하지 않아도 사이트는 Supabase 회원 식별자로 북마크를 관리합니다.

계정·즐겨찾기·세션. Supabase Auth는 회원 식별자와 인증 정보를 관리합니다. 기법을 저장하면 회원 식별자, 기법 식별자, 저장 시각을 기록합니다. 로그인 이후에는 세션 토큰을 브라우저에 저장합니다. 방문 시 외부 서비스를 요청하는 과정에서 해당 서비스에 IP 주소 등 네트워크 정보가 전달될 수 있습니다.

이름과 개인 폴더. 회원이 이름을 입력하거나 수정하면 Supabase Auth의 프로필 메타데이터에 저장합니다. 폴더를 만들면 회원 식별자, 폴더 식별자, 폴더 이름, 생성·수정 시각을 기록하고, 기법을 추가하면 폴더와 기법의 연결 및 추가 시각을 Supabase Database에 저장합니다.

제3조 개인정보의 처리 목적

계정 식별, 이메일·Google·카카오 인증, 비밀번호 재설정, 세션 유지, 마이페이지의 이메일 표시, 기기 간 즐겨찾기 저장·조회·삭제에 사용합니다. 미디어 관리 기능을 이용할 때는 로그인한 계정에 관리자 권한이 있는지 확인합니다.

제4조 Google 로그인과 데이터 이용

Google 로그인 버튼을 누르면 Supabase Auth가 Google로 이동시키며, 이메일(email)과 기본 프로필(profile) 권한을 요청합니다. 비밀번호는 Google 로그인 화면에서 처리되며 CINELIQ는 Google 계정의 비밀번호를 수집하지 않습니다. Gmail, Drive, Calendar의 접근 권한은 요청하지 않습니다.

Google은 인증에 필요한 계정 정보를 Supabase Auth에 전달합니다. Auth는 이 정보를 Google 로그인에 연결된 계정 및 인증 메타데이터로 관리하고 CINELIQ 세션을 발급합니다. CINELIQ는 세션의 이메일을 마이페이지에 표시하며, 즐겨찾기는 Google 계정 식별자 대신 Supabase 회원 식별자에 연결합니다. CINELIQ의 회원 화면은 Google 프로필 이름이나 사진을 표시하지 않습니다.

CINELIQ 웹사이트는 Google 로그인 데이터를 광고, 맞춤형 광고, 판매에 사용하지 않습니다. 이 데이터의 처리 서비스와 삭제 안내는 제5~8조에서 확인할 수 있습니다.

제5조 보유 및 이용 기간

인증 계정 정보는 Supabase Auth에 저장됩니다. 즐겨찾기는 개별 항목을 해제하거나 연결된 Auth 계정이 데이터베이스에서 삭제될 때 정리됩니다. 로그인 세션의 브라우저 저장과 종료는 제10조에서 설명합니다.

개인 폴더는 회원이 폴더를 삭제하거나 연결된 Auth 계정이 삭제될 때 제거됩니다. 폴더 삭제는 해당 폴더의 기법 연결을 제거하고 즐겨찾기는 유지합니다. 기법의 즐겨찾기를 해제하면 모든 폴더에서 해당 기법과의 연결도 제거됩니다.

운영자 확인 필요 — 계정 유지·삭제 기준, 인증·접속 로그와 백업의 보유·파기 일정, 법령에 따른 별도 보존 대상·근거·기간.

제6조 개인정보 삭제 및 회원 탈퇴

마이페이지 → 회원 정보 → 회원 탈퇴에서 삭제 안내를 확인하고 최근 로그인 검증과 최종 확인을 거쳐 탈퇴를 요청할 수 있습니다. 탈퇴가 완료되면 CINELIQ 회원 계정의 프로필 정보, 소셜 로그인 연결, 로그인 세션, 즐겨찾기, 개인 폴더와 폴더·기법 연결 정보가 삭제됩니다. 삭제된 개인 라이브러리는 재가입해도 복원되지 않습니다. Google·카카오 계정 자체와 공통 카메라 기법·공개 미디어는 삭제하지 않습니다.

관리자·Storage 파일 소유 계정이나 별도 확인 대상으로 지정된 계정은 공통 자료 보호와 필요한 확인을 위해 자동 탈퇴를 중단합니다. 제13조의 문의 이메일을 이용해 주세요. 삭제 결과를 확인하지 못한 경우 완료로 표시하지 않으며, 계정 상태를 확인할 수 있도록 안내합니다.

Supabase 보안·감사 로그와 플랫폼 백업은 라이브 회원 데이터와 별도로 관리되며 탈퇴 기능이 즉시 삭제하지 않습니다. 법적 보존 대상과 실제 보유·파기 일정은 아래 운영자 확인 항목에 따라 확정해야 합니다.

CINELIQ에서 로그아웃하거나 Google 계정의 연결 앱 설정에서 접근 권한을 철회해도 기존 CINELIQ 계정이나 즐겨찾기가 자동으로 삭제되지는 않습니다.

운영자 확인 필요 — 계정 삭제 시 본인 확인, 요청 처리 기간, 다른 기기의 세션 종료, 로그·백업에 남은 정보의 파기 절차.

제7조 개인정보의 제3자 제공

Google 로그인 과정에서 Google이 Supabase Auth로 계정 정보를 전달합니다. CINELIQ 웹사이트 코드에는 Google 프로필 정보나 회원 즐겨찾기를 광고 사업자에게 전송하는 기능이 없습니다. 외부 서비스의 역할과 처리 범위는 제8조에 기재합니다.

운영자 확인 필요 — 계약과 운영 내역을 기준으로 제3자 제공 여부와 해당하는 경우 제공받는 자, 항목, 목적, 보유 기간 및 법적 근거.

제8조 처리 위탁 및 외부 서비스

Supabase. 인증, 세션, 즐겨찾기 데이터베이스와 사이트 미디어 저장소를 제공합니다. 이메일 로그인과 비밀번호 재설정 요청을 처리하며, Google 계정 연결 정보와 회원 인증 정보를 관리합니다.

Google. Google 로그인 이용 시 계정을 인증하고 승인된 계정 정보를 Supabase Auth에 제공합니다. Google Fonts는 웹폰트를 전달합니다.

카카오. 카카오 로그인 이용 시 계정을 인증하고 동의 범위에 따른 계정 정보를 Supabase Auth에 제공합니다.

GitHub Pages와 jsDelivr. 각각 사이트 호스팅과 브라우저용 Supabase 라이브러리 전달에 사용됩니다. 사이트나 리소스를 불러올 때 해당 제공자가 접속 요청을 받습니다.

운영자 확인 필요 — 서비스별 계약 관계와 위탁 여부, 실제 수탁자 명칭과 위탁 범위, 이메일 발송 인프라.

제9조 개인정보의 국외 이전

서비스명만으로는 회원 정보가 저장·처리되는 국가를 확정할 수 없습니다.

운영자 확인 필요 — 실제 저장 리전과 접근 위치, 국외 이전에 해당하는지 여부 및 법적 근거. 해당하는 경우 이전받는 자와 연락처, 국가, 항목, 목적, 시기와 방법, 보유 기간, 거부 방법과 효과.

제10조 쿠키 및 브라우저 저장소

Supabase Auth는 현재 브라우저의 localStorage를 사용해 세션을 유지합니다. 세션에는 인증 요청에 쓰는 액세스 토큰과 갱신 토큰이 포함됩니다. 현재 기기에서 로그아웃하면 그 세션이 종료됩니다. 브라우저에서 사이트 데이터를 삭제하면 해당 브라우저에 저장된 세션을 지울 수 있습니다.

CINELIQ 자체 코드에는 쿠키나 sessionStorage에 회원 정보를 기록하는 로직과 방문 분석 스크립트가 없습니다. Google 로그인 화면과 외부 제공자의 쿠키·로그는 각 제공자의 처리 범위에 따릅니다. 이전 관리자 미디어는 해당 브라우저의 IndexedDB에 남아 있을 수 있습니다.

제11조 개인정보 보호 조치

사이트와 인증 요청은 HTTPS를 사용합니다. Google 로그인에는 PKCE를 적용합니다. Supabase의 행 수준 보안(RLS)은 로그인한 회원이 자신의 즐겨찾기만 조회·추가·삭제하도록 제한합니다. 미디어 관리 권한은 서버에서 확인하며 일반 회원에게 부여되지 않습니다. 브라우저의 Supabase 연결에는 공개 클라이언트 키를 사용합니다.

제12조 이용자의 권리와 행사 방법

마이페이지에서 계정 이메일과 즐겨찾기를 확인하고, 저장한 기법을 삭제하거나 로그아웃할 수 있습니다. 이메일 계정의 비밀번호 재설정은 로그인 화면에서 요청할 수 있습니다.

관련 법령에 따른 열람·정정·삭제·처리정지 요청은 문의하기에 안내된 이메일로 보내실 수 있습니다.
