플랫폼 보안 로그·백업은 운영 데이터 삭제와 별도로 관리됩니다. 운영자가 법적 보존 또는 별도 확인 대상으로 지정한 계정은 자동 삭제를 중단하고 문의로 안내합니다. 자세한 내용은 개인정보처리방침과 문의하기를 확인해 주세요.
